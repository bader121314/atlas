# 15 — Security Review

**Date:** 2026-11-17. **Scope:** the application as of M7 (web, API,
worker, data stores), against `docs/05-security.md`. Each area lists the
threat, the control and where it is tested. Open items are at the end.

| Area              | Threat                                                | Controls                                                                                                                                                                                                                                                                                                          | Evidence                                                                                         |
| ----------------- | ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Tenant isolation  | Reading or changing another organization's data       | Every query scoped by organization from the guard-resolved tenant; composite foreign keys and immutable tenant keys in PostgreSQL; outsiders get the same 404 as missing resources                                                                                                                                | `identity-tenancy`, `projects`, `tasks`, `search`, `attachments`, `api-tokens` integration tests |
| Private projects  | Members seeing private work                           | Effective project role computed in one policy; search, notifications, analytics, exports and automations repeat the rule in SQL                                                                                                                                                                                   | `projects`, `search`, `notifications`, `exports` tests                                           |
| Authentication    | Credential theft, session fixation                    | Argon2id; opaque 256-bit tokens stored as HMAC digests; HttpOnly, SameSite=Lax, `__Host-` cookies in production; password reset signs out every device; rate limits fail closed                                                                                                                                   | `auth-flow`, `account-security`, `rate-limits` tests                                             |
| CSRF              | Forged writes from other sites                        | Exact-Origin check on cookie-authenticated writes; bearer-token requests carry no ambient credentials                                                                                                                                                                                                             | `auth-flow`, `api-tokens` tests                                                                  |
| API tokens        | Over-broad script access                              | Scoped, per organization, expiring, hashed; tenant task routes only; settings, members, exports and token management are session-only                                                                                                                                                                             | `api-tokens` test                                                                                |
| XSS               | Script injection through task content                 | React escapes all rendered text; no `dangerouslySetInnerHTML`; content security policy (`default-src 'self'`, `object-src 'none'`, `frame-ancestors 'none'`); uploads always download as attachments with a checked type                                                                                          | smoke test checks the policy; `attachments` test checks disposition                              |
| File uploads      | Malware, disguised executables, oversized files       | Type allowlist; magic-byte check; scanner step with quarantine; 10 MB limit; size verified after upload; type-bound upload URLs; rejected files deleted                                                                                                                                                           | `attachments`, `file-types` tests                                                                |
| SSRF              | Webhooks reaching internal services or cloud metadata | https only; private, loopback, link-local, CGNAT, ULA and mapped addresses refused before saving and after DNS; connection pinned to the checked address; no redirects                                                                                                                                            | `webhooks`, `webhooks-security` tests                                                            |
| Webhook integrity | Forged or replayed deliveries                         | HMAC-SHA256 over timestamp and body; receivers reject old timestamps and repeated event ids; secrets sealed with AES-256-GCM                                                                                                                                                                                      | `webhooks-security`, `examples` tests                                                            |
| Exports           | Data leaving through spreadsheets                     | `task.export` permission; requester-only downloads; 24-hour expiry; formula-injection protection                                                                                                                                                                                                                  | `exports`, `csv-export` tests                                                                    |
| Automation        | Rules escalating privileges or looping                | Rules act as their creator and fail when the creator loses edit access; depth limit, self-trigger guard, hourly quota                                                                                                                                                                                             | `automations` test                                                                               |
| Audit access      | Administrators' trail read by the wrong people        | `audit.read` for owners and admins only, session-only; organization-scoped queries and cursors; exports are audited; networks summarized (ADR-051)                                                                                                                                                                | `audit-log-view` test                                                                            |
| Logging           | Secrets or personal data in logs                      | One JSON line per request without query strings, headers or bodies; audit metadata limited to non-sensitive values; IPs summarized                                                                                                                                                                                | `request-context` test                                                                           |
| Public links      | Unauthenticated access exposing private work          | Narrow payload built from its own query (titles, statuses, priorities, due dates only); 256-bit hashed tokens shown once; expiry, revocation, archiving and the creator losing manager rights all end access; uniform 404; no-referrer, no-store, noindex; tokens redacted from logs; per-IP rate limit (ADR-050) | `share-links`, `request-context` tests                                                           |
| Real-time         | Events reaching people without access                 | Streams pass the normal guards and recheck access every 30 seconds; envelopes carry ids only                                                                                                                                                                                                                      | `event-stream` test                                                                              |
| Infrastructure    | Exposed data stores                                   | Data in private subnets reachable only from the application; encryption at rest and in transit; TLS-only bucket policy; metrics blocked at the load balancer                                                                                                                                                      | Terraform validated in CI (ADR-043)                                                              |
| Dependencies      | Known vulnerable packages                             | `pnpm audit --prod --audit-level high` in CI; images scanned on push to ECR                                                                                                                                                                                                                                       | CI                                                                                               |

## Open items

1. **Inline scripts in the content security policy.** Next.js needs inline
   scripts for hydration; moving to per-request nonces removes
   `'unsafe-inline'`.
2. **Storage credentials.** S3 signing uses an IAM user's keys; switch to
   task-role credentials with session tokens (ADR-043).
3. **Real malware scanning.** Replace the scanner stub with ClamAV or the
   provider's scan before accepting untrusted uploads in production.
4. **Instant revocation.** Event streams recheck access every 30 seconds.
5. **Manual testing.** An external penetration test and a screen reader
   pass are still to be done.
